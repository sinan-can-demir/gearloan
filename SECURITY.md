# Security policy

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/sinan-can-demir/gearloan/security/advisories/new) to report security issues privately. Do not open a public issue.

We will acknowledge your report within 72 hours and aim to provide a fix or workaround within 14 days, depending on severity.

## Scope

This project is a music-department gear-lending system intended for internal use. Relevant concerns include authentication bypass, privilege escalation, insecure direct object references, and exposure of borrower data.

## Out of scope

- Denial-of-service attacks
- Issues requiring physical access to the server
- Social engineering of users or administrators
